# 🌍 ShamshadCodes Tours & Travel

A modern, premium, conversion-focused Tours & Travel website built with **React**, **TypeScript**, **Tailwind CSS**, and interactive lead-generation features.

---

## 🚀 Key Features

- 🧭 **13 Home Page Sections**:
  1. **Hero Section**: Destination background, strong value proposition, compact inquiry card, and trust markers.
  2. **Popular Tour Categories**: Family Holidays, Honeymoon Packages, International, Domestic, Weekend Breaks, and Group Tours.
  3. **Featured Destinations**: Visual cards for Kashmir, Goa, Dubai, Kerala, Rajasthan, Bali, Maldives, Singapore.
  4. **Popular Tour Packages**: Complete package cards with starting price, duration, and inclusions.
  5. **Why Choose Us**: 6 core trust pillars.
  6. **Custom Trip Builder**: 3-step interactive journey builder.
  7. **Travel Services**: 8 comprehensive travel services.
  8. **How It Works**: 4-step process timeline.
  9. **Customer Testimonials**: Authentic reviews with 4.9/5 average ratings.
  10. **Travel Inspiration / Blog**: Guides with in-modal article reader.
  11. **FAQ Accordion**: Filterable questions by category.
  12. **Final CTA Banner**: High-contrast conversion section.
  13. **Comprehensive Footer**: Links, contact details, social media, and policy modals.

- 💎 **Dedicated Pages & Modules**:
  - **Tour Packages Catalog (`/packages`)**: Multi-filter system (Search, Destination, Duration, Budget, Category, Sort).
  - **Tour Details Page (`/package/:id`)**: Gallery, Highlights, Day-by-Day Itinerary with activities, meals & stay, Inclusions/Exclusions, Hotel details, Transportation info, and sticky booking card.
  - **Destinations Explorer (`/destinations`)**: Explorer tabs with weather & best time to visit guides.
  - **Services Page (`/services`)**: Full travel service breakdowns.
  - **About Us Page (`/about`)**: Story, mission, core principles, and verified badges.
  - **Contact Page (`/contact`)**: Direct click-to-call, WhatsApp trigger, email, address, and interactive contact form.
  - **Enquiry / Get Quote Page (`/enquiry`)**: High-converting full quote wizard with instant WhatsApp handoff.

- ⚡ **High-Conversion & UX Features**:
  - **Multi-Currency Switcher**: Live conversions across **INR (₹)**, **USD ($)**, **AED (د.إ)**, and **EUR (€)**.
  - **Floating WhatsApp Chat Widget**: Expandable quick-inquiry prompts.
  - **Desktop Exit-Intent Modal**: ₹2,500 travel discount voucher offer (`SHAMSHAD2500`).
  - **Mobile Bottom Action Bar**: Instant 1-tap buttons for WhatsApp, Call, and Get Quote.
  - **Click-to-Call & Dynamic WhatsApp Deep-Links**: Pre-fills customer name, dates, passenger count, and destinations.

---

## 🛠️ Tech Stack

- **Framework**: React 18+ & TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: CSS transitions & Canvas Confetti
- **Bundler**: Vite

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/shamshadkhan36/toursandtravels.git
cd toursandtravels
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
